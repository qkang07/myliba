# 统一分类索引

## 1. 功能目标

MyLibA 使用“分类索引”统一文件的逻辑整理方式，不再把目录和标签作为两套并列的分类模型。

分类索引是一棵可编辑树：

- 索引节点可以创建、重命名、移动和删除。
- 文件可以直接归属多个叶子节点。
- 选中任意节点时，结果包含该节点及全部后代节点中的文件。
- 文件的物理位置、可用性和副本状态独立于分类关系；移动原文件不会改变分类。
- 新文集直接使用 catalog format 5，不存在旧分类升级、共享 baseline 或兼容迁移流程。

本功能覆盖 Go/Hub、Web 和 Android。T01–T23、真机验证和性能基线仍由用户验收。

## 2. 数据模型与约束

### 2.1 核心实体

- `classification_nodes`：索引树节点，记录 `index_id`、父节点、规范化名称、来源和删除状态。
- `classification_adds` / `classification_removes`：文件归属关系的可合并操作集合。
- `classification_memberships`：当前生效的文件—索引关系投影。
- `classification_ancestors`：祖先闭包，用于节点及后代查询。
- `classification_operations`：format 5 分类操作日志。
- `classification_conflicts`：无法自动消解的结构或字段冲突。
- `classification_source_dirs` / `classification_imports`：扫描目录到自动索引的稳定映射与导入进度。

### 2.2 不变量

1. 同一父节点下，名称按 NFC + Unicode case-fold 后唯一。
2. 树不得形成环；移动节点时必须校验目标父节点和后代关系。
3. 文件可属于多个索引；查询节点时按 `file_id` 去重。
4. 手工归属和自动扫描归属可共存；移除一种来源不应误删另一种来源。
5. 删除非空节点必须显式处理子节点和文件归属，不能静默丢数据。
6. 所有结构写入使用请求幂等键；相同请求重复提交返回同一结果。
7. 投影可以只依赖 format 5 操作日志确定性重建，不读取旧目录/标签作为分类基线。

## 3. 同步与冲突

分类操作为：

- `index.create`
- `index.update`
- `index.delete`
- `index.memberships`
- `index.resolve`

操作包含作者、单调计数器、逻辑时钟和已观察前沿。各节点按 `(clock, author, counter, opId)` 确定性重放。

并发规则：

- 不相关节点的修改直接合并。
- 同一字段并发修改按确定性胜者落地，并记录冲突。
- 并发移动造成环时保留可重放结果并记录冲突。
- 文件归属使用 add-token 与 observed-remove，避免并发新增被误删。
- 用户通过 `index.resolve` 显式解决冲突，解决动作本身也参与同步。

Hub 为每个文集持久化最小 catalog 格式。首个 format 5 记录建立边界，之后拒绝该文集的旧格式写入；状态损坏时故障闭锁。该门禁与作者 epoch/退役门禁同时生效。

## 4. 扫描、位置与保护

### 4.1 扫描生成索引

开启“保留目录结构”后，扫描器按 `library + node + root + sourceDirKey` 生成稳定自动索引，并保存目录映射。

- 重扫复用已有映射。
- 用户移动或重命名自动索引后，扫描不会把它改回原位置。
- 同一来源条目通过导入进度保证幂等。
- 扫描只改变索引和位置事实，不覆盖手工归属。

### 4.2 物理位置独立

`library_locations` 记录文件当前物理位置和历史位置。分类 API 只操作逻辑 `file_id`，不直接移动、复制或删除原文件。

因此：

- 原文件在节点内或节点间移动后，分类保持不变。
- 文件暂时不可达时，分类仍保留。
- 副本增删只改变可用性，不改变分类。

### 4.3 受保护来源

受密码保护来源采用保守可见性：

- 无法确认授权时按“未授权”处理。
- 搜索、索引计数、离线导出和读取票据使用同一保护判定。
- 已签发读取票据在真正读取前再次检查授权；撤回权限后旧票据不能继续读取。
- 仅由受保护文件支撑的自动节点对未授权请求不可见。
- 不在离线字典中泄露受保护文件、专属节点、名称或计数。

## 5. API 与交互

### 5.1 主要 API

- `GET /api/library/indexes`：根节点/子节点分页；带 `q` 时搜索任意层级节点。
- `GET /api/library/indexes/{id}`：读取节点、祖先、版本和可见计数。
- `POST /api/library/indexes`：创建节点。
- `PUT /api/library/indexes/{id}`：重命名或移动节点。
- `DELETE /api/library/indexes/{id}`：删除节点。
- `POST /api/library/index-memberships`：批量增删文件归属。
- `GET /api/library/index-conflicts`：读取冲突。
- `POST /api/library/index-conflicts/{opId}/resolve`：解决冲突。
- `GET /api/library/classification-status`：读取本机与 Hub 的格式/同步状态。
- 离线索引接口：独立分页返回文件页和索引字典页，支持 gzip + base64 压缩字典。

所有列表与搜索接口在分页前执行权限过滤，避免通过总数、游标或空页侧信道推断受保护内容。

### 5.2 Web

Web 提供：

- 左侧分类树和面包屑导航。
- 任意层级节点搜索选择器。
- 创建、重命名、移动、删除节点。
- 文件批量归类与多归属展示。
- 在线/离线统一的节点过滤。
- 离线字典独立分页、压缩存储和 schema 版本校验。

### 5.3 Android

Android 提供：

- 本地分类树、节点详情和归属编辑。
- 扫描目录自动生成索引。
- format 5 操作发布、接收、确定性重放和冲突记录。
- 离线字典分页解压、数据库缓存和查询。
- 绑定共享文集时直接采用新模型，不下载或采用迁移 baseline。

## 6. 当前实现状态

已实现：

- 分类树、祖先闭包、节点 CRUD、批量多归属和请求幂等。
- format 5 操作日志、跨节点重放、并发冲突与显式解决。
- 扫描目录自动索引、断点进度和用户编辑保持。
- 搜索、计数、票据和离线导出的受保护来源一致性；权限撤回后旧票据复核。
- 离线文件页与索引字典独立分页，字典 gzip + base64 传输。
- Web 任意节点搜索选择器。
- Hub 文集 format 5 持久门禁以及作者 epoch/退役门禁。
- Go、Web、Android 的分类入口与 format 5 互操作。

实现中已移除：

- 旧目录/标签到分类树的 shadow 对拍。
- 共享 baseline 的生成、分片、上传、下载、校验和采用。
- Hub prepare/activate/cancel 分类升级状态机。
- 对应的开发期数据库表、路由、客户端逻辑和专用测试。

以下内容不属于本次 feature 的已交付范围：

   - Android 增加本地保护域创建、解锁、撤回和来源绑定界面。
   - 多来源共享保护域、审计与密钥轮换。

2. **原文件位置迁移**
   - 在节点间复制/校验/切换当前位置/清理旧位置的完整状态机。
   - 崩溃恢复、重试、并发迁移和空间不足处理。
   - 分类关系继续只绑定 `file_id`。

3. **离线增量字典**
   - 基于 generation 的字典 delta、删除标记和断点续传。

   - 超大目录扫描批次、背压和进度可视化。

5. **体验增强**
   - Android 任意节点搜索选择器和更完整的冲突解决界面。
   - Web 拖拽移动、多选树操作、最近使用节点和键盘导航。
   - 扫描来源与自动索引映射的可视化管理。
