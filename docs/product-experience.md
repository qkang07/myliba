# 产品体验与场景验收

依据：[使用场景](senarios.md)。存储、文件夹整理、标签与检索是同等重要的主线，预览把保存与使用连接起来。

## 两条核心路径

1. 手机选择文件 → 存入云层 → 确认保存及副本状态 → 释放本机空间 → 再次读取。
2. 浏览文件夹或搜索 → 结合标签筛选 → 预览确认 → 打开、下载或分享。

存储位置变化后，第二条路径仍应成立。该目标包含跨设备文件身份、分类元数据与云目录的协同，不能仅通过界面合并实现。

## 操作语义

| 操作 | 用户可预期的结果 |
| --- | --- |
| 收录本机目录 | 索引已有文件，原件留在原处 |
| 归入文件夹 | 改变资源库中的分组，不移动或复制原件 |
| 添加标签 | 改变分类信息，不改变保存位置 |
| 复制到设备 | 在目标设备产生文件，是否收录应明确提示 |
| 存入云层 | 保存加密文件；完成状态应明确说明副本情况 |
| 释放本机空间 | 仅在安全保存条件满足后清理指定原件，保留检索信息；待实现 |
| 删除云端文件 | 与清缓存、清理本机原件分开设计；不能复用模糊的“删除”入口 |

“未归组”表示尚未归入自定义文件夹；“未添加标签”表示没有手动标签。两者独立。

## 第一轮：检索入口与语义（本轮实现范围）

- Web 首页直接搜索当前设备资源库，提供独立云层文件名搜索入口。
- 文件夹内显示设备与文件夹搜索范围；扩大到该设备全部资源时保留关键词并清除其他筛选。
- 从资源搜索进入云层搜索时带入关键词；云层目前只匹配文件名，不承诺路径与标签搜索。
- 清除筛选和切换文件夹均重置“仅显示源文件可用的资源”。排序本身不应被算作限制结果的筛选。
- 无收录目录、设备离线、无匹配结果、空文件夹提供不同提示和下一步。
- Web 与 Android 的归组操作、未添加标签筛选采用一致名称。

### 验收

1. 首页输入关键词，进入当前设备全部资源，确认查询生效。
2. 在文件夹内组合标签、来源和可用性筛选，扩大搜索后保留关键词且其他筛选已清除。
3. 开启“仅显示源文件可用的资源”再清除筛选，应能重新看到当前范围内已索引但原件不可用的条目。
4. 云层入口带入关键词；打开云层后仍可修改关键词或清空搜索。
5. 空库可以直接添加目录；没有结果时不把连接失败误报为没有文件。
6. 归组后磁盘原件位置不变；未添加标签与未归组可以分别筛选。
7. 窄屏搜索表单可换行；键盘可提交搜索，Ctrl/Cmd+K 能聚焦当前搜索框。

## 第二轮：跨设备与云层统一检索

- Web 首页及资源列表的“统一检索”、Android 远程资源库的“统一检索”合并已同步的设备索引与云文件。使用 `/api/cloud/files?scope=all`；不传 `scope` 时仍只列出云文件，兼容下载与副本状态调用方。
- 按逻辑文件 ID、原件大小和修改时间合并相同版本的位置。不会按文件名合并不同文件，也不会自动把独立导入、拥有不同逻辑 ID 的相同内容认作一个文件。不同版本保留独立结果。
- 标签新增/移除、归组/取消归组、文件夹重命名/删除与密码变更会发布替换索引快照。接收端用最新分类覆盖上传快照，空标签和空文件夹也会覆盖旧值；较旧的设备快照不会覆盖较新的上传快照。
- 分类保存在加密目录中，接收端无需原件或来源数据库。同步采用现有目录复制与后台重试机制，属于最终一致；断网期间其他设备保留上次同步的状态，重启后重新排队本地索引。
- 统一检索排除已知受密码保护的文件。加密目录同步不是密码授权共享；受保护内容仍应回到来源设备解锁。保护变更也需要传播到离线设备，不能撤回它们已经持有的旧目录。
- “仅设备索引”与“云文件”分别标识。前者显示来源位置，不显示云下载按钮；当前需要切换到来源设备读取原件。

### 覆盖边界

这不是对 Hub 所有设备的实时广播查询，只包含当前解密库已收到的索引和云目录。尚未发布索引的设备不会凭在线状态自动出现。Android 此轮接入统一结果的查询与展示，并未新增手机本地索引的加密目录发布器。

独立设备对同一逻辑文件的并发分类快照目前按发布时间确定最新状态，不做标签集合并集，以免已删除标签被恢复；设备时钟应保持同步。跨库合并、独立导入文件的内容指纹合并、分类冲突提示仍需后续设计。

### 自动验证

`catalog_search_test.go` 使用两个独立云目录、共享恢复密钥和真实 HTTP 目录同步，验证上传后的分类变更、删除、来源消失及保护变更。另验证多设备副本合并、同名不同文件不合并、不同版本不合并、旧位置不恢复，以及带小数秒的时间排序。

## 后续里程碑

### 文件身份与检索连续性

- 明确逻辑文件、内容版本和物理副本的关系；不能仅凭同名合并文件。
- 延续已实现的云目录分类同步，补齐手机本地索引发布、跨设备原件读取入口与并发冲突提示。
- 统一结果按逻辑文件呈现，展示各位置与版本；保护文件夹的访问控制继续生效。
- 离线时仍可检索已缓存的目录、标签与缩略图，区分“已找到”和“当前可读取”。

### 手机释放空间闭环

- 定义清理前的完整性与副本确认要求，包括恢复密钥可用性、原件版本未改变。
- “上传结束”不能直接等同于“可以安全清理”。清理失败或权限失效时保留原件并说明原因。
- 清理后文件仍在资源库中可检索；通过内网和外网分别验证再次预览与下载。

### 设备与传输

- 区分可浏览文件的客户端与只贡献存储的设备；展示额度、已用空间及退出影响。
- 区分内容空间与额外副本占用，避免把设备容量简单相加当作可用云盘容量。
- 传输任务脱离页面生命周期，保留整体进度、失败项目与重试入口。
- 复制完成后提供目标位置与收录入口，明确“复制成功”和“已可搜索”的区别。

### 预览与长期使用

- 原件、缩略图、视频摘要作为同一文件的不同使用方式。
- 完善最近使用、离线保留、文档预览及网络变化下的恢复体验。
- 多人账号和个人网关保留为后续范围，提前考虑文件归属、权限和密钥边界。
